\section{Supplementary Methods}

All final result-lock experiments were rerun on the remote analysis server on 2026-08-26. The runtime root was \texttt{/root/autodl-tmp/}\allowbreak\texttt{frontiers\_nutrition\_mimic\_eicu}, with MIMIC-IV v3.1 under \texttt{/root/autodl-tmp/}\allowbreak\texttt{mimiciv/mimic-iv-3.1} and eICU-CRD under \texttt{/root/autodl-tmp/}\allowbreak\texttt{eicu/base}. HTTP and HTTPS proxy environment variables were unset before execution. The server-side evidence manifest covers v7--v16 benchmark, SOTA, repair, APACHE-lock, explainability, and hospital-robustness artifacts.
