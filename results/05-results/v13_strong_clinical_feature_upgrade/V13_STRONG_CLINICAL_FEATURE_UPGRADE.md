Status date: 2026-08-26

- Source-only V13 held-out recalibrated eICU AUROC: 0.810.
- eICU calibration-only update held-out AUROC: 0.877.

## Interpretation

If domain-updated models exceed APACHE on held-out eICU, this is a local model-updating result, not source-only transport superiority. If source-only remains below APACHE, APACHE should remain a contextual clinical benchmark.
